Agent 基本原理

一份可以点的教程。不背框架 API，只讲所有 agent 框架底下那套共同的结构：一次模型调用、一次工具执行、一个把两者串起来的循环，以及围在循环外面的那一圈拦截层。

model_call tool_call

这门课的全部内容，可以压成一条因果链。每一层都解决了上一层的一个具体缺陷，同时自己又制造了一个新缺陷——下一层就是为它准备的。

怎么读

每一章都是一个可以自己走的实验。左边是 agent 的节点图，中间是它此刻的 checkpoint（内部状态），右边是它产出的对话记录。点「下一步」，你看的不是结论，是过程怎么一步步从状态里长出来。

建议按顺序读。第 04 章的循环是整门课的地基，第 05 章之后的每一个中间件，都是在那个循环上插一根钩子；第 10 章则把这个循环的内部事件翻到屏幕上来。

本书的取舍：不写任何具体框架的 API。LangGraph 的 pre_model_hook、OpenAI 的 Responses API、Claude Code 的权限层，在结构上是同一件事的三种叫法。你把这套结构记住，读任何一个框架的文档都会快得多。
