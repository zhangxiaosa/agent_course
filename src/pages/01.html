01 / MODEL

LLM 的四次跃迁

从"会续写"到"肯配合"，再到"能动手"，再到"会自己思考"，最后到"会自己用工具解决问题"。四次跃迁，每一次都不是把模型变大，而是换了一种训练信号。

2022-11-30 ChatGPT · RLHF 登场 第一次把人类偏好大规模压进模型行为
2023-03-14 → 06-13 GPT-4 · function calling 从输出文字，到输出给程序消费的参数
2025-01-20 DeepSeek-R1 · 长思维链 只奖励"答对"，思考过程自己长出来
2025 上半年 Agentic RL · 把用工具训进策略 奖励从"文字好不好"变成"任务成没成"

先纠正两处常见记忆偏差

① RLHF 不是 2022 年发明的，ChatGPT 也不是"第一次引入"。
Christiano 等人 2017 年就做了"从人类偏好里学奖励函数"，Ziegler 2019 把它用到语言模型，InstructGPT（2022 年 3 月）已经跑通了完整三步。ChatGPT 的贡献是把这套流程做到了产品级体量，让全世界第一次感到"模型在配合我"。说"第一次质变"，准确；说"第一次发明"，不准确。
② 带来"思考"的不是 DeepSeek-V3，是 DeepSeek-R1。
V3 于 2024 年 12 月发布，是 671B 总参 / 37B 激活的 MoE 底座，本身不做长思维链。R1（2025-01-20）才是那个把"思考"训出来的模型——而且 V3 正是 R1 的基座。这两个模型经常被记混，因为它们在同一个技术报告家族里，发布只隔了一个月。

四次跃迁，改的都不是参数量

把四次跃迁摊开看，会发现一件很一致的事：模型规模在稳定增长，但真正带来能力断层的，是奖励信号换了一种。

跃迁训练信号能力增量同时引入的新故障
RLHF人类对两个回答的排序从"续写"变成"回应"奖励模型只是近似 → reward hacking；多样性下降
function call不训练，纯 schema 约束解码输出可被程序消费函数名幻觉、参数不合 schema、越权调用
长思维链答案对不对（可规则验证）多步推理、自我检查思考 token 直接变钱；延迟暴涨；过程不可控
agentic RL整条轨迹的最终任务成败自己判断何时用哪个工具环境搭建成本极高；奖励可被 hack；轨迹采样极贵

这也解释了为什么第 05 章之后要讲那么多中间件：每一次能力跃迁，都是把一个新的不可控因素放进了系统。中间件就是给这些不可控因素装的保险。

关于 agentic RL 的时间坐标

你提到"具体对应哪个模型、什么时间，我不确定"。它不是某一天某一个模型的单点事件，而是 2025 年上半年密集出现的一条线。三个可查的坐标：

  • 2025-04-15 · ReTool（字节 Seed）——第一次把代码解释器插进强化学习的 rollout 里：模型边推理边执行代码，只按最终答案给奖励。AIME24 67.0% / 400 步 对比纯文本 RL 基线 40.0% / 1080 步。训练中自发出现"代码写错了自己改"的行为。
  • 2025-07-11 · Kimi K2——第一次把 agentic RL 做成完整、可复现的工程体系：3000+ 真实 MCP 工具演化出 20000+ 合成工具，生成数千个 agent 与任务，用模拟环境跑多轮轨迹，只保留判定成功的那些；奖励侧把可验证奖励（RLVR）和自评 rubric 拼在一起。SWE-bench Verified 65.8 Tau2-Bench 66.1，且是不开思考模式的成绩。
  • 2025-08 · DeepSeek-V3.1——混合推理架构，post-training 明确针对工具使用与 agent 任务加强。

这三者共享同一个转向：训练目标从"这段文本的概率"变成了"这条轨迹的结局"。模型不再学"怎么说得像"，而学"怎么做得成"。第 04 章那个循环，正是被训练的那个对象。
